# Ecommerce Data Warehouse

This project is part of my Data Engineering learning journey.

I built this project to understand how real-world data warehouses work using SQL Server and layered warehouse architecture.

Instead of only practicing isolated SQL queries, I wanted to learn how data flows through a complete system — from raw data to cleaned business-ready analytics.

---

## What This Project Covers

- Loading raw e-commerce data
- Building Bronze, Silver, and Gold layers
- Data cleaning and transformations
- Creating analytical tables
- Writing business-focused SQL queries
- Understanding warehouse design concepts

---

## Architecture

Raw Data → Bronze Layer → Silver Layer → Gold Layer

### Bronze Layer
Stores raw ingested data without major transformations.

### Silver Layer
Cleaned and standardized data ready for processing.

### Gold Layer
Business-ready analytical tables for reporting and insights.
